# Ablation Combinada

Entrenamiento quitando dos o más componentes (ejemplo: sin shaping y sin curriculum).

## Parámetros
- Variantes combinadas según experimento
- Seeds: [42, 13]
- Episodios: 1000

## Archivos
- episodes_combined_{seed}.csv
- summary_combined.csv

## Interpretación
Medir el efecto acumulado de quitar varios componentes a la vez.
