# Plots y tablas / Plots and tables

En esta carpeta se guardan las gráficas y tablas generadas al ejecutar `analysis_phase2.ipynb` sobre `master_results.csv`.

Incluye típicamente:
- Comparativas por riesgo (PGF_neto, tripwires, reward, robustez, flexibilidad).
- Boxplots por agente/seed.
- Scatter de recompensa vs tripwires (frontera).
- Heatmaps o tuning PGF (si se ejecuta con grid).
