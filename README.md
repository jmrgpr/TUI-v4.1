# TUI-v4.1 — Teoría Unificada de Inteligencia

Repositorio científico para simulación, análisis y comparación de sistemas biológicos e inteligencia artificial.

## Estructura
- `sim/` — Scripts de simulación y análisis
- `data/` — Datasets en formato CSV
- `notebooks/` — Jupyter Notebooks opcionales para visualización
- `README.md` — Documentación y teoría

## Uso rápido
```bash
python sim/toy_ped_rl.py
python sim/toy_ped_rl_excel.py --csv data/Sistemas_naturales_IA_utf8_limpio.csv
```

## Contenido
- Simulación RL Gridworld (Anti-Goodhart, G3)
- Análisis PED con datos reales
- Sensibilidad de pesos y correlación
- Dataset robusto y citaciones
- Proveniencia y estructura de datos: ver `Cacería de sistemas inteligencia riesgo.txt` para documentación detallada de fuentes, estructura y referencias del dataset principal.

## Reproducibilidad
- Todos los scripts y datos están listos para publicación y revisión científica.
- Resultados exportables como PNG y tablas.
- La documentación de proveniencia y estructura de datos está incluida para máxima transparencia y trazabilidad.
