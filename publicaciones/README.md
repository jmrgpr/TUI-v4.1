## 📚 Documentos Principales / Main Documents

### 1. **PGF_v3_Technical_Report.md** ⭐ (NEW - Dec 2025)

**Título completo**: *"Prudential Gating Function v3: Multi-Seed Validation of a Risk-Aware Reward Shaping Mechanism for Reinforcement Learning"*

**Tipo**: Technical Report (formato académico)  
**Páginas**: ~30 (Markdown, ~6800 palabras)  
**Estado**: Listo para arXiv/Zenodo  
**Idioma**: Inglés (English)

**Contenido**:
- Validación multi-seed de PGF v3 (3 semillas: 42, 123, 456)
- Ratio promedio: **38.93% ± 0.59%** (CV = 1.52% - reproducibilidad excelente)
- Mejora vs baseline: **+131.7%** (v1 → v3)
- Análisis honesto del "Alignment Tax" (impuesto de alineación)
- Validación en entorno benigno: **105%** (Simbiosis supera a Control)
- Comparación estadística con v2.1: p < 0.001, Cohen's d = 23.15
